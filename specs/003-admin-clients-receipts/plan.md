# Implementation Plan: Admin Portal with Client Management & Service Receipt Generation

**Branch**: `003-admin-clients-receipts` | **Date**: 2026-09-08 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/003-admin-clients-receipts/spec.md` and user preferences (Drizzle ORM + Neon Database, no public navigation buttons, direct URL `/admin`).

## Summary

Implement a secure, hidden administrative portal accessed directly via `/admin` (no public entry point in the main portfolio UI) for the website owner. The feature enables:
1. Direct credential-based authentication and secure session management.
2. Complete Client & Project lifecycle management (CRM for freelance websites and systems) persisted in **Neon Serverless Postgres** via **Drizzle ORM**.
3. Dynamic "Recibo de Prestação de Serviços" generation with automatic provider & client data population, currency in full words, and custom notes.
4. Clean vector PDF export/download and direct transactional email dispatch to clients using the **Resend API**.
5. Centralized Provider Profile settings (document, contact, PIX key) stored in the database.

## Technical Context

**Language/Version**: TypeScript 5 / Next.js 16.3 (App Router, React 19)

**Primary Dependencies**:
- `drizzle-orm` + `@neondatabase/serverless` (Neon Postgres ORM & HTTP pooling)
- `drizzle-kit` (Schema migrations and database push)
- `resend` (Transactional receipt delivery)
- `zod` (Input schema validation & type inference)
- `jose` + `bcryptjs` (JWT session cookies & password hashing)
- `react-hook-form` + `@hookform/resolvers` (Admin form handling)
- `@react-pdf/renderer` / `jspdf` (High-fidelity vector PDF generation)

**Storage**: Neon Serverless Postgres (Cloud PostgreSQL Database)

**Testing**: Playwright e2e tests (`/tests/e2e/admin.spec.ts`) & contract unit validation

**Target Platform**: Vercel / Node.js Serverless Runtime

**Project Type**: Next.js Fullstack Web Application (Static Public Portfolio + Serverless Protected Admin Portal)

**Performance Goals**:
- Admin route response < 200ms
- Database query execution < 50ms via Neon HTTP driver
- PDF rendering and download generation < 1.5s

**Constraints**:
- Strictly NO public visual links/buttons to `/admin` in the portfolio header, navigation, or footer.
- 100% Type-safe database queries and Server Actions.
- Resilient error handling with no unhandled server crashes.

## Complexity Tracking

> No constitution violations detected. Drizzle ORM and Neon Postgres align with ratified Constitution v1.1.0.

| Item | Why Needed | Alternative Rejected Because |
|---|---|---|
| Drizzle ORM | Type-safe queries and lightweight Neon integration | Raw SQL lacks automated schema types; Prisma introduces large binaries in Serverless. |
| Direct URL (`/admin`) | Keep public portfolio uncluttered with zero visual clues for visitors | Public admin link exposes internal administrative tooling unnecessarily. |
| Snapshot fields in `service_receipts` | Legal and historical receipt integrity | Relying strictly on foreign keys would mutate past issued receipts if a client changes name or CNPJ. |
